# 🌤️ Skycast Weather App

## 📌 About the Project

Skycast Weather App is a simple and user-friendly weather application developed using HTML, CSS, and JavaScript.

It is designed to help users view weather information through a clean and attractive interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Simple and user-friendly interface
- Responsive design
- Weather application interface
- Easy navigation

## 📂 Project Structure

```text
Skycast-Weather-App/
│
├── index.html
├── style.css
└── script.js
```

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the application.
